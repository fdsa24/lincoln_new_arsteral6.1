# 설계·데이터·한계

## 요청 경로
브라우저 → Origin/수업 코드/소유자 쿠키 → 실제 본문 크기·스키마 검사
→ 서버 세션과 프리셋 스냅샷 → 원자적 생성 시도 예약/세션 잠금
→ 당시 사료만 넣은 링컨 호출 → 형식·등록 ID 검사
→ 현대 해설 별도 호출 → 저장 → 대사·인용·해설 분리 UI.

모델 호출 동안 DB 트랜잭션을 열어두지 않습니다. 120초 임대와 세션 행 잠금으로 중복 생성을 제어합니다.
앱 처리 신호는 최대 60초, Next.js 함수 maxDuration은 90초입니다. 실제 배포 플랜 제한은 별도입니다.
각 모델 호출의 출력 상한은 4096토큰이며 답변+해설로 최대 2번 호출합니다.
각 호출의 일시적 HTTP 오류만 최대 1번 재시도하므로 한 생성 시도에서 최대 4회 HTTP 요청이 가능합니다.
입력은 4,000자, 성공 대화 최대 6쌍·문맥 14,000자입니다. 글자 수 제한은 정확한 토큰 계산이 아닙니다.
입력 자료는 고정 소규모 발췌입니다. 더 큰 코퍼스로 확장하면 별도 토큰 예산·검색 처리가 필요합니다.

## 저장 모델
- lincoln_sessions: UUID, 소유자 토큰의 SHA-256, 프리셋 JSON 스냅샷, 모드, 작성·만료 시각
- lincoln_turns: 세션+요청 UUID 복합 PK, 세션 내 순번 고유, 질문, 상태, 답변 JSON, 오류 코드, 임대 시각
- lincoln_quotas: UTC 일/분 버킷, 생성 시도 예약 횟수, 정리 시각

답변 JSON에는 배우 대사, 실제로 삽입한 인용·출처 복사본, 현대 해설, 모델 이름, 프롬프트·사료 버전, 공급자 사용량 정보가 포함됩니다.
Source와 Quote는 이 입문판에서 DB 테이블이 아닌 버전 관리된 TypeScript 카탈로그입니다.
사용자가 임의 URL을 등록하거나 서버가 외부 페이지를 스크랩하는 기능은 없으므로 런타임 검색 HTML/SSRF 경로도 추가하지 않았습니다.

## 인증의 정확한 범위
이 버전은 계정 서비스가 아니라 **무작위 소유자 쿠키 + 공유 수업 코드** 구조입니다.
쿠키는 32바이트 임의 토큰이며 JS에서 읽지 못하고 DB에는 해시만 저장됩니다.
복구 가능한 계정·기기간 동기화는 없습니다. 코드를 아는 사람에게 자기 쿠키의 방만 보입니다.
공유 코드 자체는 개인 신원을 증명하지 않습니다. 코드 유출 시 교체하고 재배포하세요.
신규 쿠키 남발에 대해 소유자 제한만으로 방어하지 못합니다. 유료 생성에는 별도 DB 글로벌 시도 상한이 적용됩니다.
가입/입장 시도와 비생성 DB 요청은 WAF·IP 제한이 별도로 필요합니다.

## 재시도와 멱등성
같은 요청 UUID+동일 본문은 완료/실패 결과를 재사용합니다. 본문 변경은 409입니다.
미완료 요청에 대한 재제출은 처리 중 409, 임대 만료 뒤에는 실패로 반환합니다.
브라우저에서는 전송 중복을 동기적으로 막고 날짜/방 변경 시 AbortController와 참조 동일성 검사를 모두 사용합니다.
브라우저 취소·서버 타임아웃은 Google 처리·과금 취소를 보장하지 않습니다.
네트워크 오류는 자동 재시도하지 않으며 HTTP 429/502/503/504만 제한적으로 재시도합니다.

## 날짜·사료의 정확한 범위
- 프리셋은 UI 날짜 당일 사건을 제외하는 보수적 경계로 시작합니다.
- 1858년에는 대통령 정체성을 쓰지 않습니다.
- 1865년 4월 14일 오전의 인물은 이후 사건을 이미 아는 것으로 행동하지 않아야 합니다.
- 모델 사전학습 지식과 사용자 입력은 완전히 제거할 수 없습니다. 프롬프트+자료 필터는 미래 지식 차단의 보증이 아닙니다.
- 같은 모델의 두 번 호출은 입력을 분리할 뿐 독립 학술 검증이 아닙니다.
- 인용 ID와 날짜 검증은 결정적 검사지만 대사의 모든 주장에 대한 의미 검증은 아닙니다.
- 3개의 공개 전사문 발췌만 들어 있습니다. 원본 이미지·이본·번역 전문가 검토는 미완료입니다.
- 1858년과 1865년 상세 재현에는 사료 확충이 선행되어야 합니다.
