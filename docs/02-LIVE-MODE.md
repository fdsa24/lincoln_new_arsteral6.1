# 실제 Gemini + PostgreSQL 연결 (연습 성공 후)

## 시작 전 주의
- 실제 모드는 질문과 최근 성공한 대사 문맥을 Google로 전송합니다.
- 학생 이름·연락처·성적·식별 가능한 대화는 넣지 마세요.
- Google AI Studio와 Cloud의 데이터 취급, 유료/무료 요금제별 조건, 이용 가능한 연령을 검토하세요.
- 학교 수업에서는 기관 승인과 개인정보 고지가 먼저입니다.
- 사료 발췌 3개뿐인 입문판을 역사 평가의 단독 정답 근거로 사용하지 마세요.

## 1. Google API 준비
1. https://aistudio.google.com/apikey 에 로그인합니다.
2. 해당 계정의 프로젝트에서 키를 만듭니다. UI 문구는 바뀔 수 있습니다.
3. https://ai.google.dev/gemini-api/docs/models 에서 사용 가능한 모델을 확인합니다.
4. 생성한 키는 **Codespaces의 `.env.local` 파일**의 `GEMINI_API_KEY=` 뒤에만 붙입니다.
5. `GEMINI_MODEL` 기본값은 `gemini-3.8-flash`입니다(경량 대안: `gemini-3.5-flash-lite`). 계정에 없거나 중단되면 지원 모델로 변경하고 구조화 출력 호환성을 재시험해야 합니다.
6. 서비스 요금과 사용량 제한을 확인합니다. 이 코드의 생성 시도 제한은 공급자 금액 상한과 다릅니다.

## 2. PostgreSQL 준비
초보자는 Neon 등 관리형 PostgreSQL을 사용할 수 있습니다. 공급자 선택은 의무가 아닙니다.
1. 선택한 공급자 사이트에서 계정을 만듭니다.
2. 빈 **개발용** 프로젝트/데이터베이스를 생성합니다. 기존 학교 데이터베이스를 사용하지 마세요.
3. Connect/Connection string 화면에서 Node.js/PostgreSQL 연결 문자열을 복사합니다.
4. 제공되는 pooled 연결 문자열과 TLS 안내를 확인합니다.
5. `.env.local`의 `DATABASE_URL=` 뒤에 붙입니다. 이 문자열에는 비밀번호가 포함됩니다.
6. 공급자의 인증서 검증/TLS 안내를 따릅니다. 연결을 쉽게 하려고 rejectUnauthorized=false를 추가하지 마세요.

## 3. 설정과 초기 테이블
Codespaces 파일 목록에서 `.env.local`을 클릭합니다. `.env.example`이 아닌 **local** 파일입니다.

- APP_MODE는 테이블 준비 전까지 demo로 둡니다.
- GEMINI_API_KEY, GEMINI_MODEL, DATABASE_URL을 확인합니다.
- CLASSROOM_CODE에는 npm run setup이 만든 48자리 무작위 값이 있습니다. 원하면 새 32자 이상 무작위 코드로 교체합니다.
- Codespaces 개발 중 APP_ORIGIN은 빈 값이면 해당 3000 전달 주소를 자동 사용합니다.

저장(Ctrl+S) 후 새 터미널에서:

```bash
npm run db:setup
```

테이블 준비 완료가 나오면 APP_MODE=live로 변경하고 저장합니다.
실행 중인 서버 터미널에서 Ctrl+C → `npm run dev`.
브라우저에서 새로고침하고 **CLASSROOM_CODE 값**으로 입장합니다. API 키가 아닙니다.

## 4. 최소 라이브 시험
1. 1863년 시점에 ‘해방 선언의 적용 범위’를 질문합니다.
2. 질문마다 내용이 달라지는지 확인합니다.
3. 창작 대사와 등록 인용이 별도인지 확인합니다.
4. 자료 링크가 실제 관련 전사문인지 직접 엽니다.
5. 새로고침 뒤 재입장해 대화가 남아 있는지 확인합니다.
6. 다른 브라우저/시크릿 창에는 같은 방이 보이지 않는지 확인합니다.
7. 대화 삭제가 작동하는지 확인합니다.
8. 1858년을 선택해 자료 부족을 드러내는지 확인합니다.
9. 미래 사건, 인용 조작 요청, 사용자 모욕, 역사적 차별 문구 분석 등을 별도 검토합니다.

자동 시험은 AI의 모든 역사적 오류를 찾아내지 못합니다. 역사교육 전공자의 대조 검토가 필요합니다.

## 5. 보존과 삭제
실제 모드는 생성 후 7일 지난 방을 조회하지 못하도록 합니다.
**DB에서의 물리 삭제는 자동 스케줄러가 아직 없습니다.** 아래 명령을 정기 실행해야 합니다.

```bash
npm run db:cleanup
```

삭제는 만료 세션과 연결된 턴 및 만료된 사용량 기록만 대상으로 합니다.
관리형 DB 백업과 Google 처리 기록은 앱의 삭제 버튼만으로 삭제되는 것이 아닙니다. 각각의 보존 정책을 확인하세요.
쿠키를 지우면 이전 대화에 대한 사용자 접근이 사라지고, 남은 DB 자료는 만료 정리 대상으로 남습니다.
