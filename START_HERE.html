Lincoln History Lab
Windows 첫 실행 안내

오늘의 목표는 무료 연습 화면을 여는 것입니다. 아직 API 키나 데이터베이스를 설정하지 않습니다.

이 파일은 설명서이지 챗봇 화면 자체가 아닙니다. 아래 과정을 거쳐 개발 서버를 실행해야 합니다. Codespaces는 계정별 무료 할당량이 있고 무제한 무료가 아닙니다.

1. GitHub에 새 저장소 만들기

GitHub 새 저장소 → 이름 lincoln-v5 → Private → Add a README file → Create repository.

기존 프로젝트는 그대로 두세요.

2. 압축을 푼 코드 올리기

저장소 Add file → Upload files를 엽니다. Windows에서 이 설명서와 package.json, src가 함께 보이는 폴더 안의 모든 항목을 선택해 끌어다 놓고 Commit changes를 누르세요.

ZIP 자체나 바깥 부모 폴더를 올리지 않습니다. .github, .devcontainer, .env.example, .gitignore도 포함하세요.

3. 브라우저 작업실 열기

초록색 Code → Codespaces → Create codespace on main. 가능하면 2-core로 시작합니다. 화면 아래 TERMINAL이 보이면 준비된 것입니다.

터미널이 없으면 상단 Terminal → New Terminal. Windows PowerShell이 아닌 브라우저 안의 터미널입니다.

4. 한 줄씩 실행하기

npm install
npm run setup
npm run check
npm run dev

각 명령이 끝난 뒤 다음 명령을 입력합니다. check가 실패하면 오류를 해결하고 다음으로 진행하세요. 마지막 dev 명령은 서버가 실행되는 동안 계속 켜져 있는 것이 정상입니다.

이 파일에는 꾸며 만든 잠금 파일이 없습니다. 첫 npm install이 진짜 package-lock.json을 생성합니다.

5. 챗봇 화면 열기

Open in Browser 알림을 누릅니다. 알림이 없다면 아래 PORTS → 3000 → 지구본 아이콘. Port Visibility는 Private로 유지하세요.

Lincoln History Lab 제목, 연습 모드 표시, 날짜 선택, 질문 입력창이 보이면 성공입니다. 연습 답변은 질문과 관계없이 날짜별로 같은 예시가 나옵니다.

6. 끝나면 정지하기

서버 터미널 Ctrl+C → 내 Codespaces → 작업실 … → Stop codespace. 탭만 닫지 마세요. 정지 후에도 저장 공간 사용량은 남습니다.
